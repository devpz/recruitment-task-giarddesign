# GiardDesign – Recruitment Task

Landing page created as part of a frontend recruitment task.

## Tech Stack

- React
- TypeScript
- TanStack Start
- Tailwind CSS
- shadcn/ui
- Bun

## Getting Started

Install dependencies:

```bash
bun install
```

Run the development server:

```bash
bun dev
```

Create a production build:

```bash
bun run build
```

## About

The goal of this project was to recreate the provided design with a focus on responsive layout, reusable components, and clean code.

During development I also migrated the project from the initial Lovable setup to a standard TanStack Start configuration.
